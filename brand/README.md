# MaxStyle

Парикмахер-стилист Максим Смоляков, студия MaxStyle, Москва (Гостиничная ул., 9А, корп. 3, гостиница «Восток», 2 этаж, каб. 235, метро и МЦД «Окружная»). Полный брендбук: https://claude.ai/artifact/19LDFGYJs61R5xHQt8g2K4

## Файлы

| Файл | Где использовать |
| --- | --- |
| `logo/maxstyle-logo.svg` | Шапка сайта на светлом фоне (основной вариант) |
| `logo/maxstyle-logo-dark.svg` | На тёмном фоне и на `--panel` |

| `fonts/fonts.css`, `fonts/fonts.html` | Forum (логотип, заголовки) и Golos Text (текст, цены) |

## Правила для сайта

- Светлая тема по умолчанию: фон `--stone`, карточки `--stone-raised`, текст `--graphite`, подписи `--steel`.
- Кнопка «Записаться онлайн» - фон `--oxblood`, текст `--on-oxblood`, скругление `--radius-sm`.
- Латунь `--brass` - только линии 1px, рамки и иконки. Цены текстом - `--brass-ink`, класс `.price`.
- Тёмные секции (отзывы, контакты) - `--panel`, текст `--on-panel`.
- Углы почти прямые, тени не используются, много воздуха: между секциями `--space-64`.
- Заголовки - Forum одним весом, текст - Golos Text. Выравнивание по левому краю.
- Тон спокойный, на «вы», без восклицаний и эмодзи. Только короткое тире «-».
- Отзывы - без имён и фото клиентов без их согласия.
