# MaxStyle

Одностраничник парикмахера-стилиста Максима Смолякова, студия MaxStyle, Москва.

Опубликован через GitHub Pages из ветки `main`, корень репозитория.

## Как править

- `index.html` - тексты, прайс, галерея (у карточки галереи `data-photo` - id фото на Unsplash).
- `styles.css` - оформление. Цвета только из `brand/colors/brand.css`.
- `gallery.js` - фильтр и просмотр фото.
- `img/` - свои фотографии.

После коммита в `main` сайт обновляется примерно за минуту.
